# The Broadsheet: ylab.co design concept

Design exploration from October 2026, drawing on hscompute.com (newspaper display serif, justified columns, cut-out coupon form, Q&A grid) and noord.dev (hairline rule grid, About / Focus / Approach strip, work tiles). It features the new AI evals offer through a sample "eval sheet".

- `index.html`: homepage concept as a static page (preview at `/design/broadsheet/`)
- `system.html`: type, color and component sheet
- `source/`: the original design-canvas files (`.dc.html` artboards and `canvas.json`)

Fonts: Newsreader, Libre Franklin, JetBrains Mono (Google Fonts). Colors: ground #F8F7F5, ink #161514, muted #5F5A55, rule #D9D5CF, accent #8A2B1D.

Square-bracketed text like [pricing] is placeholder copy. This is not wired into the live site's layouts.
